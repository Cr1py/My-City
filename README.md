# MyCity Project
MyCity is a mobile app project built using Flutter framework that aims to provide information about different cities around the world. This README.md file contains instructions on how to download, install, and run MyCity on your local development environment.

## Prerequisites
Before you can run MyCity, you need to have the following software installed on your computer:

- Node.js Version v18.15.0: You can download and install Node.js from the official website: https://nodejs.org/
- Firebase: MyCity uses Firebase for authentication and database management. You need to create a Firebase project and obtain the necessary configuration details to connect MyCity to Firebase. You can create a Firebase project here: https://firebase.google.com/

## Download and Installation
To download and install MyCity, follow these steps:

- Clone the MyCity repository from GitHub: git clone https://github.com/your-username/MyCity.git
- Change your current directory to the cloned repository: cd ~/MyCity
- Install the required dependencies using Node.js: npm install

## Running the App
MyCity is built using Flutter, and it runs best on Android Studio. To run MyCity, follow these steps:

- Open the MyCity project in Android Studio.
- Choose an emulator to run the app. We the Google Pixel 6 emulator running Android spk 26.
- In the terminal, navigate to the root directory of the MyCity project.
- Run the app using the Flutter command: flutter run --no-sound-null-safety
- If you encounter a red screen error on the emulator, you can try to refresh the app by pressing "r" in the terminal. You may need to do this once to initialize the app.
